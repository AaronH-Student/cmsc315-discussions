# Unit 1 Discussion: Python OOP, Namespaces, and Copying

## Overview

This assignment explores object-oriented programming (OOP) concepts in Python, including inheritance, namespaces, and object copying.

## Implementation
I kept the implementation simple and focused to demonstrate each desired concept. I established a 'Sailor' parent class and a 'Pirate' child class maintaining the parent class behavior while adding new 'Pirate' specific behavior and attributes. I intentionally added mutable nested data in 'experience' to demonstrate the difference between shallow and deep copying. I built the functions around demonstrating the desired learning objectives and used the 'main' function to run the entire suite of demonstrations/tests.
